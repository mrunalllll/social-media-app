# Buzzly - Mini Social Media App

Features: user profiles, posts and comments, like and follow system.

Stack: HTML, CSS, JavaScript (frontend) | Express.js (backend) | SQLite (database)

## How to run
1. Install Node.js
2. Open a terminal in this folder
3. `npm install`
4. `npm start`
5. Open http://localhost:3000

## Database tables
users, posts, comments, likes, followers (created automatically on first run)
